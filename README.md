# Rouaa Zouheiry Portfolio — V2

A light, modern personal-brand portfolio for Rouaa Zouheiry.

## Publish/update existing GitHub repo

Copy these files into your existing `rouaa-portfolio` local folder, replacing:
- index.html
- style.css
- script.js

Keep the `assets` folder.

Then run:

```bash
git add .
git commit -m "Redesign Rouaa portfolio"
git push
```

GitHub Pages will update automatically once it is enabled for the repository.
